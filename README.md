# Cognitive-Vision-Language-Model-analyzer

Cognitive-Vision-Language-Model-analyzer is a research-driven project that investigates **cognitive capabilities** of modern **Vision-Language Models (VLMs)** — such as reasoning, attention, memory, and visual understanding. It provides tools and evaluation scripts to assess how well these models exhibit human-like cognitive traits when interpreting multimodal inputs.

---

## Objectives

- Assess VLMs on tasks that simulate cognitive functions
- Analyze model behavior using benchmark datasets
- Evaluate performance on reasoning, perception, memory, and language grounding tasks
- Visualize model outputs and internal attention maps (if available)

---
## Supported Models
 - OpenAI CLIP
 - BLIP / BLIP-2
 - LLaVA
 - Flamingo (Coming soon)
 - Kosmos-2
